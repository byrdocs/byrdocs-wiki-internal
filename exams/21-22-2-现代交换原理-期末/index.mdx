## 一、判断题（共 20 分，每题 1 分）

1. PSTN 网络的程控交换机与 NGN 网络的软交换机都可以采用电路交换方式交换话音信息，并且都将保存用户数据。<Blank>✗</Blank>

<Solution>
PSTN 程控交换机采用电路交换并保存用户数据；软交换控制的是 IP 分组语音呼叫，不把话音按电路交换方式直接交换，题干把二者等同。
</Solution>

2. MPLS 与 ATM 相似，都具有路由选择与数据转发分开进行的特点，都需要为每一次通信业务建立一个新的连接。<Blank>✗</Blank>

<Solution>
MPLS 可预先建立供多个业务流复用的 LSP，不要求每次通信都新建连接；ATM 虚连接与 MPLS LSP 的建立粒度也不同。
</Solution>

3. SIP 电话系统中，话音流都使用 SIP 协议来传输，因此得名 SIP 电话。<Blank>✗</Blank>

<Solution>
SIP 负责会话信令，实际话音媒体通常由 RTP/UDP 承载。
</Solution>

4. 程控交换机中央交换网络的 TST 网络是用于交换统计时分复用信号。<Blank>✗</Blank>

<Solution>
TST 网络交换固定 PCM 时隙，属于同步时分交换，不是统计时分复用。
</Solution>

5. 5G 网络中通过微基站密集部署，可改善网络覆盖，大幅度提升系统容量。<Blank>✓</Blank>

<Solution>
微基站密集部署缩短无线距离并提高空间复用度，可改善覆盖和系统容量。
</Solution>

6. 程控交换机用户模块的用户电路板属于话路子系统。<Blank>✓</Blank>

<Solution>
用户电路板完成馈电、振铃、监视、编译码等话路接口功能，属于话路子系统。
</Solution>

7. 无论是电话交换系统还是分组数据交换系统，一般都是由信息传输子系统和控制子系统构成。<Blank>✓</Blank>

<Solution>
交换系统通常可抽象为信息传输/交换子系统和控制子系统。
</Solution>

8. LTE 网络中话音和数据都可以采用 IP 分组方式传送。<Blank>✓</Blank>

<Solution>
LTE 数据业务基于 IP；VoLTE 也使用 IMS 与 RTP 在分组域承载语音。
</Solution>

9. 空分结构的交换单元只适合交换模拟信号，无法交换数字时分复用信号。<Blank>✗</Blank>

<Solution>
空分交换单元只表示连接在空间位置上分离，既可交换模拟信号，也可交换数字信号。
</Solution>

10. Benes 网络是一种可重排无阻塞的网络。<Blank>✓</Blank>

<Solution>
Benes 网络通过重排已有连接可为新的输入输出对找到路径，是可重排无阻塞网络。
</Solution>

11. TST 网络是一种多通道网络。<Blank>✓</Blank>

<Solution>
TST 中间的 S 级和多个内部时隙为连接提供多个可选内部通道。
</Solution>

12. SIP 协议是 IMS 系统的核心协议。<Blank>✓</Blank>

<Solution>
IMS 的会话控制以 SIP 为核心协议。
</Solution>

13. SIP 用途广泛，在移动通信上也有应用。<Blank>✓</Blank>

<Solution>
SIP 广泛用于固定和移动 IP 多媒体通信，IMS 就是其移动网络应用。
</Solution>

14. MPLS 中，FEC 就是 IP 地址前缀。<Blank>✗</Blank>

<Solution>
FEC 是转发等价类，可由目的前缀、源地址、业务类型、QoS 等多个字段划分，不等同于 IP 前缀。
</Solution>

15. MPLS 网络在数据传送过程中利用标记 LABEL 标识路由，并且这个标记 LABEL 可以有多级。<Blank>✓</Blank>

<Solution>
MPLS 支持标签栈，可压入多层标签实现 VPN、隧道和分层 LSP。
</Solution>

16. SIP 是应用层协议，采用基于文本的消息编码方式。<Blank>✓</Blank>

<Solution>
SIP 是应用层协议，消息采用类似 HTTP 的文本编码。
</Solution>

17. ATM 中，路由标记是本地（逐段）有效的，交换机负责进行标记转换；MPLS 中，路由标记是全程有效的，路由器无需进行标记转换。<Blank>✗</Blank>

<Solution>
ATM 的 VPI/VCI 和 MPLS 标签都只在相邻链路上局部有效，中间节点均需进行标记置换。
</Solution>

18. 无论是程控系统提供的电话会议，还是 IP 环境下提供的电话会议，都有会议混音处理，即让参会者 A 同时听到讲话者 B、讲话者 C 的语音。会议混音借助了交换网络多对一的交换能力。<Blank>✓</Blank>

<Solution>
会议桥需要把多个讲话者的媒体流混合后送给参会者，体现多路输入汇聚到一路输出处理。
</Solution>

19. 移动终端在 GSM 网内移动时，由于位置区发生了变化，所以 MSC 会触发移动终端的位置更新。<Blank>✗</Blank>

<Solution>
位置区改变后由移动终端检测并发起位置更新，MSC/VLR 处理更新，不能说由 MSC 单方面触发。
</Solution>

20. 蜂窝移动通信网中，手机从一个位置区进入到另一个位置区，就会进行漫游。<Blank>✗</Blank>

<Solution>
跨位置区只需位置更新；漫游通常指进入非归属网络或其他服务区，二者不能等同。
</Solution>

## 三、填空题

### 1.（3 分）

某双处理机的交换系统，在 BHCA 计算中，单 CPU 忙时用于呼叫处理的时间开销为 0.88，固有开销为 0.29，处理一个呼叫的平均时间为 36ms。则这个交换系统的总体 BHCA 为（次/小时）。

注：只填写数字，不能带空格。

<Solution>

**答案：118000**

单 CPU 的有效呼叫处理开销为 $0.88 - 0.29 = 0.59$，能力为 $0.59 \times 3600 / 0.036 = 59000$ 次/小时。双处理机负荷分担时总体能力为 $2 \times 59000 = 118000$ 次/小时。

</Solution>

### 5.（10 分）

使用 10 个 $20 \times 30$ 的交换单元做为入口级，10 个 $30 \times 20$ 的交换单元做为出口级，构建一个 3 级 CLOS 网络。该网络的规模是 $200 \times$ ______，中间级有 ______ 个交换单元，每个单元有 ______ 条入线，有 ______ 条出线；该网络的阻塞情况为 ______（a 表示有内部阻塞，b 表示可重排无阻塞，c 表示严格无阻塞）。（注意：只能填写数字或小写字母 a、b、c，不要有空格）

<Solution>

**答案：200，30，10，10，b**

入口级共 10 个、每个 20 入线，故网络规模为 $200 \times 200$。入口单元有 30 条出线，所以中间级有 $m = 30$ 个交换单元；每个中间单元连接 10 个入口单元和 10 个出口单元，规模为 $10 \times 10$。因 $m = 30 \ge n = 20$，满足可重排无阻塞；但 $30 < 2n - 1 = 39$，不满足严格无阻塞。

</Solution>
